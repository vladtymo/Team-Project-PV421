Патерн Декоратор (Decorator)

Опис

Патерн Декоратор (Decorator) належить до структурних патернів проектування. Він дозволяє динамічно додавати нову функціональність об’єктам, не змінюючи їхній код. Декоратори обгортають початковий об’єкт, реалізуючи той самий інтерфейс, і можуть розширювати його поведінку.

UML-діаграма (спрощено)

Component ↑ ConcreteComponent ↑ Decorator ↑ ConcreteDecorator

Приклад (на Python)


from abc import ABC, abstractmethod

# Базовий компонент
class Coffee(ABC):
    @abstractmethod
    def cost(self):
        pass

# Конкретний компонент
class SimpleCoffee(Coffee):
    def cost(self):
        return 10

# Базовий декоратор
class CoffeeDecorator(Coffee):
    def __init__(self, coffee):
        self._coffee = coffee

    def cost(self):
        return self._coffee.cost()

# Конкретні декоратори
class MilkDecorator(CoffeeDecorator):
    def cost(self):
        return super().cost() + 3

class SugarDecorator(CoffeeDecorator):
    def cost(self):
        return super().cost() + 2

# Використання
coffee = SimpleCoffee()
print(coffee.cost())  # 10

coffee_with_milk = MilkDecorator(coffee)
print(coffee_with_milk.cost())  # 13

coffee_with_milk_and_sugar = SugarDecorator(coffee_with_milk)
print(coffee_with_milk_and_sugar.cost())  # 15

Переваги

  • Гнучке додавання нової поведінки без зміни існуючого коду.
  • Можна комбінувати декоратори для створення складних ефектів.
  • Відповідає принципу відкритості/закритості (OCP).

Недоліки

  • Код може стати складнішим через велику кількість обгорток.
  • Важче налагоджувати, коли багато рівнів декорування.
