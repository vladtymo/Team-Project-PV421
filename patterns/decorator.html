Design Pattern: Decorator

Problem

Уявімо, що у вас є клас, який надає базову функціональність, наприклад, компонент інтерфейсу або об’єкт, що обчислює щось. Тепер потрібно додати до нього додаткову поведінку — логування, кешування, валідацію або нові візуальні ефекти.

Можна було б створити підкласи з розширеною поведінкою, але що робити, якщо таких комбінацій потрібно десятки? Наприклад: Кава з молоком, з молоком і цукром, з вершками, з вершками і карамеллю… — кількість класів швидко росте!

У результаті код стає важко підтримувати, і з’являється дублікат логіки у різних підкласах.

Solution

Патерн Декоратор пропонує замість створення нових підкласів динамічно “обгортати” об’єкти іншими об’єктами, що додають потрібну поведінку.

Декоратор реалізує той самий інтерфейс, що і вихідний об’єкт, і має посилання на нього. Викликаючи методи, декоратор може виконати додаткову логіку до або після делегування виклику базовому об’єкту.

Таким чином, ви можете комбінувати декоратори в будь-якому порядку, щоб створювати складну поведінку без зміни початкового коду класів.

Real-World Analogy

Уяви, що ти замовляєш каву в кав’ярні. Ти починаєш із простої кави (базовий компонент), а потім можеш додати до неї молоко, цукор, вершки, сироп тощо.

Кожна добавка — це декоратор, який змінює смак (поведінку) базового напою, не змінюючи рецепт самої кави.

Structure

1. Component — спільний інтерфейс для об’єктів, до яких можуть додаватися нові обов’язки динамічно.

2. Concrete Component — клас, що реалізує базову поведінку.

3. Decorator — абстрактний клас, який реалізує той самий інтерфейс і містить посилання на компонент.

4. Concrete Decorators — класи, які додають нову поведінку, викликаючи базову логіку через композицію.

# Приклад коду (Python)


from abc import ABC, abstractmethod

# Компонент
class Coffee(ABC):
    @abstractmethod
    def cost(self):
        pass

# Конкретний компонент
class SimpleCoffee(Coffee):
    def cost(self):
        return 10

# Базовий декоратор
class CoffeeDecorator(Coffee):
    def __init__(self, coffee):
        self._coffee = coffee

    def cost(self):
        return self._coffee.cost()

# Конкретні декоратори
class MilkDecorator(CoffeeDecorator):
    def cost(self):
        return super().cost() + 3

class SugarDecorator(CoffeeDecorator):
    def cost(self):
        return super().cost() + 2

# Використання
coffee = SimpleCoffee()
print(coffee.cost())  # 10

coffee_with_milk = MilkDecorator(coffee)
print(coffee_with_milk.cost())  # 13

coffee_with_milk_and_sugar = SugarDecorator(coffee_with_milk)
print(coffee_with_milk_and_sugar.cost())  # 15
