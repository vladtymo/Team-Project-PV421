The Builder Pattern

Builder is a creational design pattern that lets you construct complex objects step by step, separating the construction process from the final representation.

Concept

The main idea is to extract the object construction logic into a separate Builder, which assembles the final product step by step.

  • Separates construction from representation
  • Allows creating different variations of an object
  • Useful for objects with complex structures

Example (Java)


// Product
class House {
    String walls;
    String roof;
    String interior;
}

// Builder
interface HouseBuilder {
    void buildWalls();
    void buildRoof();
    void buildInterior();
    House getResult();
}

// Concrete Builder
class WoodenHouseBuilder implements HouseBuilder {
    private House house = new House();

    public void buildWalls() { house.walls = "Wooden walls"; }
    public void buildRoof() { house.roof = "Shingle roof"; }
    public void buildInterior() { house.interior = "Wooden interior"; }

    public House getResult() { return house; }
}

// Director
class Director {
    private HouseBuilder builder;
    Director(HouseBuilder builder) { this.builder = builder; }

    House construct() {
        builder.buildWalls();
        builder.buildRoof();
        builder.buildInterior();
        return builder.getResult();
    }
}

// Usage
public class Main {
    public static void main(String[] args) {
        HouseBuilder builder = new WoodenHouseBuilder();
        Director director = new Director(builder);
        House house = director.construct();
        System.out.println(house.walls);
    }
}

When to Use

  • When an object requires step-by-step creation
  • When different representations of the same object are needed
  • When the construction process should be independent of the parts
